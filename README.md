# Flashcards 🧠

A fun and interactive flashcard application built using Python and Tkinter.  
This project helps users practice and memorize concepts through simple digital flashcards with an easy-to-use graphical interface.

## Features
- Interactive flashcard learning
- Simple and clean GUI
- Built with Python and Tkinter
- Beginner-friendly project

## Technologies Used
- Python
- Tkinter

## Purpose
This project was created as a fun way to explore GUI development in Python while building an engaging learning tool.
